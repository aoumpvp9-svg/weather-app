# 🌤️ WeatherOn (웨더온) - 실시간 현재 날씨 & 예보 웹 애플리케이션

별도의 유료 API 키나 복잡한 등록 절차 없이, 전 세계 어디서나 현재 날씨와 시간별/주간 예보를 무료로 조회할 수 있는 고성능 반응형 웹 애플리케이션입니다.

---

## 🌟 주요 기능 및 특징

1. **무료 & No API Key 공개 API 연동**:
   - **기상 데이터**: [Open-Meteo API](https://open-meteo.com/) (현재 기온, 체감 기온, 습도, 풍속, 기압, 강수량, 24시간 시간별 예보, 7일간 주간 예보)
   - **위치 & 지오코딩**: [OpenStreetMap Nominatim](https://nominatim.openstreetmap.org/) 및 내장 프리셋 사전 (한국어/영어 도시 및 전 세계 모든 지역 지원)
2. **날씨 상태별 시각화 (이모지 & 테마)**:
   - WMO(세계기상기구) 4677 기상 코드를 분석하여 맑음(☀️/🌙), 흐림(⛅/☁️), 비(🌧️), 눈(❄️), 천둥번개(⛈️), 안개(🌫️) 등 직관적인 이모지와 배지 제공
   - 현재 날씨 상태 및 주간/야간 여부에 따라 **배경 그라데이션 및 파티클 애니메이션(빗방울, 눈송이, 반짝이는 별빛)**이 동적으로 자동 전환
3. **친절한 에러 핸들링**:
   - 존재하지 않는 지역 입력 시 명확하고 친절한 안내 메시지 및 대체 추천 검색어 칩 제공
   - 네트워크/서버 오류 시 재시도 버튼 제공
4. **편의 기능**:
   - **GPS 내 위치 조회**: 현재 위치의 날씨를 원클릭으로 조회 (역지오코딩 지원)
   - **온도 단위 전환**: 섭씨(°C) / 화씨(°F) 원클릭 토글 (풍속 단위도 km/h ↔ mph 자동 변환)
   - **검색어 자동완성 & 추천 칩**: 서울, 부산, 제주, 도쿄, 뉴욕 등 주요 도시 빠른 원클릭 검색
   - **최근 검색 기록**: 최근 검색한 지역 저장 (LocalStorage 연동) 및 개별/전체 삭제 지원
   - **실시간 시계**: 헤더에 실시간 초 단위 시계 표시
5. **모던 글래스모피즘 & 완벽한 반응형**:
   - 모바일, 태블릿, 데스크탑 전 기기 최적화 레이아웃 지원

## 🚀 실행 방법

### 방법 1: 로컬 웹 서버 실행 (권장)
현재 백그라운드에서 로컬 서버가 실행 중입니다:
- 브라우저를 열고 **`http://localhost:3000`**에 접속하세요.

서버를 다시 시작하려면 터미널에서 다음 명령어를 실행합니다:
```bash
node server.js
```

### 방법 2: 브라우저로 직접 열기
- `d:\유재훈\12_UI제작\weather-app\index.html` 파일을 브라우저(Chrome, Edge 등)로 더블 클릭하여 바로 열어보실 수도 있습니다.
